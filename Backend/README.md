# Backend - Flask + MySQL Production Deployment on Render

This directory contains the Flask REST API, templates, static files, database initialization script, and Dockerfile for deploying the MySQL database and Flask application on Render.

## Deployment Architecture

```
Netlify (Frontend)
       │
       │ HTTPS REST API requests (CORS enabled)
       ▼
Render (Flask Web Service: auth-flask-api)
       │
       │ Internal TCP:3306 (Private Network)
       ▼
Render (MySQL Docker Private Service: auth-mysql with persistent disk)
```

## Deploying on Render via Blueprint

1. Push this repository to GitHub. The root `render.yaml` defines both services:
   - `auth-mysql`: Private Docker service running MySQL 8.0 with a persistent SSD disk (`/var/lib/mysql`).
   - `auth-flask-api`: Python 3 Web Service running Flask with Gunicorn.
2. In your Render Dashboard, click **New + → Blueprint**.
3. Select your GitHub repository.
4. Render will parse `render.yaml` at the root and automatically configure:
   - Root directory for Flask: `Backend`
   - Build command: `pip install -r requirements.txt`
   - Start command: `gunicorn app:app`
   - Root directory for MySQL: `Backend/database`
   - Internal credentials and connection linking via `fromService`
5. Click **Apply**. Render will generate secure credentials and launch both services.
6. Once deployed, test the database connection by visiting:
   `https://auth-flask-api.onrender.com/api/test-db`
   Expected response:
   ```json
   {
     "success": true,
     "message": "MySQL connection successful",
     "database": "authentication_db"
   }
   ```

## Environment Variables

### Flask Service (`auth-flask-api`)
| Variable | Value / Source | Description |
|---|---|---|
| `DB_HOST` | Linked from `auth-mysql.host` | Internal private hostname (`auth-mysql`) |
| `DB_PORT` | `3306` | MySQL internal listening port |
| `DB_NAME` | `authentication_db` | MySQL database name |
| `DB_USER` | `auth_user` | MySQL user |
| `DB_PASSWORD` | Linked from `auth-mysql.MYSQL_PASSWORD` | Secure generated password |
| `FRONTEND_ORIGIN` | `*` or `https://your-site.netlify.app` | Allowed CORS origins for Netlify |
| `PORT` | Set automatically by Render (`10000`) | Listening port |

### MySQL Private Service (`auth-mysql`)
| Variable | Value | Description |
|---|---|---|
| `MYSQL_DATABASE` | `authentication_db` | Initial database created on startup |
| `MYSQL_USER` | `auth_user` | Application database user |
| `MYSQL_PASSWORD` | Auto-generated by Render | Secure application password |
| `MYSQL_ROOT_PASSWORD` | Auto-generated by Render | MySQL root user password |

### Persistent Disk
- **Mount Path**: `/var/lib/mysql`
- **Disk Name**: `mysql-data`
- **Size**: 1 GB

## Available API Endpoints

- `GET /api/health` - Liveness check, returns service status
- `GET /api/test-db` - Verifies live MySQL database connectivity
- `POST /api/register` - Registers a user with bcrypt hashed password
  - Request body: `{ "name": "User", "email": "user@example.com", "password": "password123" }`
- `POST /api/login` - Authenticates user credentials
  - Request body: `{ "email": "user@example.com", "password": "password123" }`
- `GET /api/profile?id=<id>` or `?email=<email>` - Retrieves profile data
- `GET /api/users` - Lists registered users (id, name, email, created_at)
- `GET /profile` - Renders server-side profile view
