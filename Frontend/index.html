Practical 4: Render Backend & MySQL Setup

Practical 4 runs on Render with a private MySQL Docker service and persistent disk storage:

# Render Service Environment Variables
DB_HOST: auth-mysql (Internal Private Hostname)
DB_PORT: 3306
DB_USER: auth_user
DB_PASSWORD: [Configured via Render Blueprint]
DB_NAME: authentication_db
FRONTEND_ORIGIN: https://your-site.netlify.app (or *)

Local run with Python & MySQL:

cd Backend
pip install -r requirements.txt
python app.py
